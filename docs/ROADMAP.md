# Roadmap

## Near term
- Connect GTFS-Realtime feeds so the map reflects real conditions
- Gate-aware dynamic routing (today gate wait is a decision input, not a routing constraint)
- Accessibility-aware routing and non-scooter alternatives as baseline constraints
- Post-match egress modeling, typically the harder half of match day
- Mobile PWA with a wallet-based Digital Fan Pass

## Transferability
- Planning-level checks done: MetLife Stadium (New York/NJ) and Lumen Field (Seattle)
- Full pass across the 11 US host cities: rail/BRT access, GTFS-RT availability, station-to-gate
  walk distance, readiness note, published as a transparency matrix with sources and check dates
- Pilot with one US host city (Seattle or New York/NJ)

## Legacy
- Event adapters: match, concert, marathon, festival
- Reusable gate/traffic state schema and an "adopt this template for your city" guide
- Named post-FIFA owner per deployment, with documented limitations and data-swap instructions
