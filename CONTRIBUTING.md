# Contributing

EcoMove 2026 is a concept prototype maintained solo. Contributions are welcome in two forms.

1. Issues: bug reports, data-source suggestions, accessibility findings. If you spot a figure that
   looks inconsistent, open an issue with the file and line; docs/DATA_DICTIONARY.md is the source
   of truth for every locked parameter.
2. Pull requests: small, scoped changes. Keep docs/DESIGN_SYSTEM.md as the only source of visual
   truth, and label every new figure as sourced or illustrative.

Ground rules:
- No live-data claims: the prototype is simulated by design, and the UI says so.
- No negative-carbon figures: emissions are positive, with avoided-vs-driving stated separately.
- AI assistance stays limited to code translation; design decisions remain human-led and reviewed.

By contributing you agree that your work is licensed under MIT, matching the project.
